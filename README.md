# WmTur · Landing page em React

Landing de vendas da WmTur (Jericoacoara): tela de carregamento com o 4x4 na praia, primeira tela com fotos dos passeios, passeios, translados, frota e galeria estilo feed. Todos os botões levam ao WhatsApp.

## Rodar em 3 comandos

```bash
npm install
npm run dev        # abre em http://localhost:5173
npm run build      # gera a pasta dist/ para publicar
```

Precisa do Node.js 18 ou mais novo.

- Número do WhatsApp, Instagram e tempo do carregamento: `src/config.js`
- Passeios, preços, rotas, frota e galeria: `src/data.js`
- Cores e estilos: `src/styles.css`

O guia completo, passo a passo, está em **GUIA-PASSO-A-PASSO.md**.
A pasta `referencia/` tem o arquivo de design original, só para consulta.
